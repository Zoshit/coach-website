# 🎉 Nataliya Dyadichenko — Платформа з продажу квитків на події

[![en](https://img.shields.io/badge/lang-English-blue.svg)](README.md)   [![uk](https://img.shields.io/badge/lang-Українська-yellow.svg)](README.uk.md)

> Повнофункціональна e-commerce платформа на Django для перегляду та купівлі квитків на події. Репозиторій містить лише опис проєкту — вихідний код закритий за умовами конфіденційності клієнта.

## Огляд
Масштабна веб-платформа для продажу квитків на події з повним циклом e-commerce: перегляд подій за категоріями, додавання в кошик, оформлення замовлення та онлайн-оплата. Проєкт включає каталог з керуванням через адмінку, систему знижок та динамічні сторінки для кожної події.

## Можливості

### 🗂️ Каталог подій
- Події, організовані за категоріями, з повноцінним керуванням даними через бекенд
- Індивідуальна динамічна сторінка для кожної події, що генерується з бази даних (наприклад, `/shop/product/30/...`)

### ⭐ Відгуки
- Розділ з відгуками клієнтів з каруселлю автоматичної прокрутки

### 🛒 Кошик
- Повністю реалізований кошик — додавання та видалення товарів у реальному часі
- Збереження стану кошика протягом усього процесу оформлення замовлення

### 💳 Оформлення та оплата
- Окремий процес створення замовлення (`/orders/create/`)
- Інтегрована система онлайн-оплати

### ⚙️ Керування через адмінку
- Система знижок, що налаштовується прямо через адмін-панель Django
- Увімкнення/вимкнення відображення товарів на сайті без втручання в код

## Технічний стек

![Django](https://img.shields.io/badge/Django-092E20?style=for-the-badge&logo=django&logoColor=white)
![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

- `Django` — бекенд, каталог та система категорій на ORM, логіка кошика та замовлень
- `Django Admin` — кастомна панель керування знижками та видимістю товарів
- `JavaScript` — інтерактивність кошика та карусель відгуків з автопрокруткою
- `HTML/CSS` — адаптивна верстка вітрини та сторінок подій
